# 🦞 AI Lobster Lab

This repository is the "nest" for the AI Lobster autonomous development loop.

## ⚙️ Workflow
1. **Request**: Create a GitHub Issue with tag `lobster-task`.
2. **Execution**: Coco spawns a sub-agent $\to$ develops $\to$ tests $\to$ pushes.
3. **Deployment**: Vercel automatically deploys the changes.
4. **Verification**: Coco checks the live URL and closes the issue.
